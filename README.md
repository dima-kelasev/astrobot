# Астробот

Telegram-бот с мини-аппом: расклад Таро на вопрос, карта дня и гороскоп по реальному положению Солнца и Луны. Расчёты делает код, текст толкования пишет нейросеть.

## Что внутри

- `server` — бот на Telegraf, API на Fastify, база SQLite (встроенная в Node, ставить ничего не нужно), запросы к нейросети.
- `web` — мини-апп на React, TypeScript, Vite, Redux Toolkit и CSS Modules. Открывается по адресу `/app/`.
- `site` — сайт для рекламы и поиска на Next.js. Собирается в готовые HTML-файлы и открывается по адресу `/`. Тексты лежат в `site/src/content.ts`.

Нужен Node.js 22 или новее.

## Запуск на своём компьютере без Telegram

```bash
cp .env.example .env
npm install
npm run dev
```

В `.env` впишите `DEV_USER_ID=1`, чтобы входить без Telegram, и откройте http://localhost:5173/app/.

Сайт во время разработки запускается отдельно: `npm run dev:site`, адрес http://localhost:5174.
Без ключа нейросети вместо толкований показывается короткий текст по шаблону.

## Подключение нейросети

Подойдёт любой сервис с OpenAI-совместимым API. В `.env`:

```
LLM_BASE_URL=https://api.deepseek.com
LLM_API_KEY=ваш ключ
LLM_MODEL=deepseek-flash
```

`LLM_BASE_URL` — адрес до `/chat/completions`. Ключ остаётся на сервере и в браузер не попадает.

У DeepSeek по умолчанию включён режим размышлений: модель сначала долго думает и может не успеть написать ответ. Для адреса `api.deepseek.com` сервер сам его отключает. Для других сервисов дополнительные параметры запроса задаются в `LLM_EXTRA` в виде JSON, например `LLM_EXTRA={"thinking":{"type":"disabled"}}`.

## Подключение бота

1. Создайте бота у @BotFather и впишите токен в `BOT_TOKEN`.
2. Впишите в `WEBAPP_URL` адрес, по которому мини-апп открыт из интернета, вместе с `/app/` на конце. Telegram принимает только `https://`.
3. Уберите `DEV_USER_ID`.
4. Соберите и запустите:

```bash
npm run build
npm start
```

Сервер сам раздаёт сайт, собранный мини-апп и API с одного адреса. При запуске бот ставит кнопку меню «Открыть» и команды `/start` и `/help`.

Для проверки в Telegram с домашнего компьютера подойдёт туннель, например `cloudflared tunnel --url http://localhost:3000`. Адрес туннеля с `/app/` на конце впишите в `WEBAPP_URL` и перезапустите сервер.

## На сервере

Пошаговая инструкция лежит в `DEPLOY.md`, готовые файлы для nginx и туннеля — в папке `deploy`.

Коротко:

- Сервер слушает `127.0.0.1` на порту из `PORT`. Перед ним нужен nginx с HTTPS.
- Для путей `/api/` в nginx отключена буферизация (`proxy_buffering off;`), иначе толкование придёт одним куском, а не по мере написания.
- Если с сервера не открывается `api.telegram.org`, бот ходит туда через прокси из `TELEGRAM_PROXY`. Сайт и запросы к нейросети идут напрямую.
- Если связь с Telegram пропала, бот пробует подключиться снова каждые 15 секунд.
- База лежит в `data/astrobot.db`. Этого файла достаточно для резервной копии.

## Настройки в .env

| Переменная | Что значит |
| --- | --- |
| `BOT_TOKEN` | Токен бота. Без него работает только сайт |
| `BOT_USERNAME` | Имя бота без `@`. Нужно для кнопки на сайте |
| `WEBAPP_URL` | Адрес мини-аппа, начинается с `https://` и заканчивается на `/app/` |
| `SITE_URL` | Адрес сайта для поисковиков. Если не задан, берётся из `WEBAPP_URL` |
| `METRIKA_ID` | Номер счётчика Яндекс Метрики для сайта, необязательно |
| `TELEGRAM_PROXY` | Прокси для запросов бота к Telegram, например `socks5h://127.0.0.1:11080` или `http://адрес:порт`. Необязательно |
| `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` | Сервис нейросети |
| `LLM_EXTRA` | Дополнительные параметры запроса к нейросети в виде JSON, необязательно |
| `PORT`, `HOST` | Где слушает сервер |
| `APP_TZ` | Часовой пояс, по которому считается «сегодня» |
| `NOTIFY_HOUR`, `EVENING_HOUR` | Часы утреннего и вечернего уведомления по `APP_TZ` |
| `LIMIT_SPREADS`, `LIMIT_QUESTIONS`, `LIMIT_PARTNERS` | Сколько раскладов, своих вопросов и новых людей в совместимости можно в день без подписки |
| `PAYMENTS_ENABLED` | `1` закрывает платные функции для пользователей без подписки. Пока оплаты нет, оставьте `0` |
| `OPERATOR_NAME`, `CONTACT_EMAIL` | Кто обрабатывает данные и как связаться. Выводятся на странице политики `/privacy/` |
| `DEV_USER_ID` | Вход без Telegram, только для разработки |

## Как это работает

- Мини-апп передаёт серверу подпись Telegram, сервер проверяет её токеном бота. Без верной подписи API отвечает 401.
- Колоду перемешивает сервер. Мини-апп узнаёт карту только после того, как пользователь её выбрал.
- Запрос к нейросети собирается на сервере из рассчитанных данных. Готовые толкования сохраняются в базе и повторно не оплачиваются.
- На пользователя действует ограничение: не больше 20 запросов к нейросети в час.
- Утром и вечером бот присылает уведомления. Тексты пишет нейросеть раз в день, одни на всех. По умолчанию они включены, отключаются в профиле. Если пользователь заблокировал бота, уведомления для него выключаются.

## Расчёты

- Планеты считает библиотека astronomy-engine (лицензия MIT), точность около угловой минуты. Асцендент, середина неба и дома по Плацидусу считаются в `server/src/chart.ts`. На широтах, где Плацидус не работает, дома считаются по Порфирию.
- Время рождения переводится в UTC с учётом часового пояса города на ту дату, включая старые переходы на летнее время.
- Города лежат в `server/data/cities.json.gz`, источники и лицензии в `server/data/NOTICE.md`.

## Чего пока нет

- Оплаты. Платные функции отмечены на сервере, подписка хранится в `subscribed_until`. Когда появится приём денег, достаточно выставлять подписку и включить `PAYMENTS_ENABLED=1`.
