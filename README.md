# Астробот

Telegram-бот с мини-аппом: расклад Таро на вопрос, карта дня и гороскоп по реальному положению Солнца и Луны. Расчёты делает код, текст толкования пишет нейросеть.

## Что внутри

- `server` — бот на Telegraf, API на Fastify, база SQLite (встроенная в Node, ставить ничего не нужно), запросы к нейросети.
- `web` — мини-апп на React, TypeScript, Vite, Redux Toolkit и CSS Modules.

Нужен Node.js 22 или новее.

## Запуск на своём компьютере без Telegram

```bash
cp .env.example .env
npm install
npm run dev
```

В `.env` впишите `DEV_USER_ID=1`, чтобы входить без Telegram, и откройте http://localhost:5173.
Без ключа нейросети вместо толкований показывается короткий текст по шаблону.

## Подключение нейросети

Подойдёт любой сервис с OpenAI-совместимым API. В `.env`:

```
LLM_BASE_URL=https://api.deepseek.com
LLM_API_KEY=ваш ключ
LLM_MODEL=deepseek-flash
```

`LLM_BASE_URL` — адрес до `/chat/completions`. Ключ остаётся на сервере и в браузер не попадает.

У DeepSeek по умолчанию включён режим размышлений: модель сначала долго думает и может не успеть написать ответ. Для адреса `api.deepseek.com` сервер сам его отключает. Для других сервисов дополнительные параметры запроса задаются в `LLM_EXTRA` в виде JSON, например `LLM_EXTRA={"thinking":{"type":"disabled"}}`.

## Подключение бота

1. Создайте бота у @BotFather и впишите токен в `BOT_TOKEN`.
2. Впишите в `WEBAPP_URL` адрес, по которому мини-апп открыт из интернета. Telegram принимает только `https://`.
3. Уберите `DEV_USER_ID`.
4. Соберите и запустите:

```bash
npm run build
npm start
```

Сервер сам раздаёт собранный мини-апп и API с одного адреса. При запуске бот ставит кнопку меню «Открыть» и команды `/start` и `/help`.

Для проверки в Telegram с домашнего компьютера подойдёт туннель, например `cloudflared tunnel --url http://localhost:3000`. Адрес туннеля впишите в `WEBAPP_URL` и перезапустите сервер.

## На сервере

```bash
npm ci
npm run build
pm2 start ecosystem.config.cjs
```

- Сервер слушает `127.0.0.1:3000`. Перед ним нужен nginx с HTTPS, который отдаёт всё на этот порт.
- Для путей `/api/` отключите буферизацию в nginx (`proxy_buffering off;`), иначе толкование придёт одним куском, а не по мере написания.
- Бот должен работать там, где доступен `api.telegram.org`.
- База лежит в `data/astrobot.db`. Этого файла достаточно для резервной копии.

## Настройки в .env

| Переменная | Что значит |
| --- | --- |
| `BOT_TOKEN` | Токен бота. Без него работает только сайт |
| `WEBAPP_URL` | Адрес мини-аппа, начинается с `https://` |
| `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` | Сервис нейросети |
| `LLM_EXTRA` | Дополнительные параметры запроса к нейросети в виде JSON, необязательно |
| `PORT`, `HOST` | Где слушает сервер |
| `APP_TZ` | Часовой пояс, по которому считается «сегодня» |
| `FREE_SPREADS_PER_DAY` | Сколько раскладов в день бесплатно |
| `NOTIFY_HOUR` | Час утренней рассылки по `APP_TZ` |
| `DEV_USER_ID` | Вход без Telegram, только для разработки |

## Как это работает

- Мини-апп передаёт серверу подпись Telegram, сервер проверяет её токеном бота. Без верной подписи API отвечает 401.
- Колоду перемешивает сервер. Мини-апп узнаёт карту только после того, как пользователь её выбрал.
- Запрос к нейросети собирается на сервере из рассчитанных данных. Готовые толкования сохраняются в базе и повторно не оплачиваются.
- На пользователя действует ограничение: не больше 20 запросов к нейросети в час.
- Утренняя рассылка включается в профиле и уходит раз в день. Если пользователь заблокировал бота, рассылка для него отключается.

## Чего пока нет

- Оплаты. Счётчик бесплатных раскладов, платные расклады и подписка в базе уже предусмотрены (`credits`, `subscribed_until`), не хватает только приёма денег.
- Натальной карты и совместимости.
- Истории раскладов в интерфейсе, хотя в базе она сохраняется.
